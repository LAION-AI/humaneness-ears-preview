# Humaneness Ears — public research preview

A separate GitHub Pages test publication of the [LAION Humaneness Ears](https://huggingface.co/laion/humaneness-ears-base-medium) blog article and paper draft. The production LAION blog is not modified.

- `index.html` and `styles.css`: standalone article preview in a LAION-inspired visual style.
- `source/humaneness-ears.md`: production-blog-format article source, with original LAION front matter and image paths.
- `assets/`: original hero artwork and data-grounded vector figures.
- `paper/main.pdf`: six-page manuscript draft.
- `paper/overleaf_upload.zip`: upload to Overleaf with `main.tex` as root.
- `paper/technical-code/`: pinned copy of public model/training code; weights remain on Hugging Face.
- `paper/evidence/`: compact frozen result snapshots and checksums for review.

Pages serves the root of `main` with `.nojekyll`. This is a public feedback preview, not a peer-reviewed paper or an update to `laion.ai`.
